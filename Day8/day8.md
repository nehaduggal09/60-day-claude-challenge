# Day 8: Environmental Health Analyzer Dashboard

## Overview
This project is an **Environmental Health Analyzer** interactive web dashboard built using Claude AI. The application processes environmental parameters, visualizes health-related risk factors, and provides dynamic data filtering.

---

## Features
- **Real-time Data Filtering:** Filter environmental metrics by region, risk level, and pollutant types.
- **Interactive Data Visualizations:** Dynamic charts highlighting Air Quality Index (AQI), water quality, and environmental risk scores.
- **Key Health Metrics:** High-level overview cards displaying critical environmental indicators.
- **Export & Download Options:** Native HTML/JS downloadable single-page application.

---


## Technical Stack
- **AI Generator:** Claude (Anthropic)
- **Frontend:** HTML5, CSS3, JavaScript (Chart.js / Tailwind CSS via CDN)
- **Version Control:** Git & GitHub

---

## Key Learnings
1. **AI-Driven Prototyping:** Learned how to structure prompts effectively to generate a full single-file interactive web application in one go.
2. **Dashboard UX/UI:** Understood how to lay out key performance metrics alongside interactive data filters for optimal user readability.
3. **DOM Manipulation & Charting:** Interacted with dynamic JavaScript logic for client-side filtering without needing a heavy backend.
