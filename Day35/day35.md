# 🧩 Prompt Puzzle — Master AI Prompting Through Play

> A premium, interactive prompting game designed to help users **learn AI prompting by playing**, practicing, and improving their prompt-building skills.

## 🎯 Overview

**Prompt Puzzle** is a single-file offline web application that turns AI prompt engineering into a game.

Players solve randomized prompting challenges by:

- Building prompts from correct prompt blocks
- Cleaning weak or poorly structured prompts
- Choosing the best prompt for a given goal
- Learning practical prompt-engineering principles
- Tracking accuracy, speed, moves, mistakes, hints, and optimization bonuses
- Reviewing a personalized Prompt Performance Report

The application is designed for students, beginners, AI learners, creators, marketers, developers, researchers, and professionals who want to improve their ability to communicate effectively with AI.

## ✨ Features

### 🧠 Prompting Practice

The game generates **6–8 randomized scenarios** based on the selected:

- Domain
- Difficulty

Each scenario contains:

- Desired Output
- Correct Prompt Blocks
- Distractor Blocks
- Weak Prompt
- Optimized Prompt
- Over-Engineered Prompt
- Weak AI Output
- Optimized AI Output
- Prompt Principle

---

## 🎮 Challenge Types

The application contains exactly three challenge types.

### 1. 🧩 Build the Prompt

Players construct the best prompt by arranging the correct prompt blocks in the right order while avoiding distractors.

Skills practiced:

- Context
- Role
- Goal
- Constraints
- Output format
- Examples
- Evaluation criteria

---

### 2. 🧹 Clean the Prompt

Players improve a weak or messy prompt by identifying unnecessary, vague, contradictory, or poorly structured instructions.

The goal is to transform the prompt into a clear and effective instruction.

---

### 3. 🏆 Choose the Best Prompt

Players compare multiple prompt options and select the prompt most likely to generate the desired output.

The game explains **why** the selected prompt is effective.

---

## 📊 Live Scoring

The game tracks performance in real time using:

- **Accuracy**
- **Time**
- **Moves**
- **Wrong Placements**
- **Hints Used**
- **Optimization Bonus**

The scoring system rewards:

- Correct decisions
- Fast completion
- Fewer mistakes
- Efficient prompt construction
- Better optimization

## 🏅 Prompt Performance Report

After completing the game, players receive a detailed performance report containing:

### Prompt Score

Overall score based on gameplay performance and prompting quality.

### Rating

Example ratings:

- Beginner
- Developing
- Skilled
- Advanced
- Prompt Master

### Rank

Players receive a rank based on their final performance.

### 🧬 Prompt DNA

A visual breakdown of prompting strengths such as:

- Clarity
- Context
- Specificity
- Constraints
- Structure
- Output Control
- Reasoning
- Optimization

### 💬 Personalized Feedback

The application analyzes gameplay and provides personalized feedback based on mistakes and strengths.

### 🎯 Next Milestone

Players receive a recommended next goal for improving their prompting ability.

### 🚀 Final Optimized Prompt

The application displays the strongest optimized prompt generated from the completed challenge.

## 🌐 Offline Support

The application is designed to run simply by opening the HTML file.

### Requirements

- Everything must exist inside **ONE HTML file**
- No backend
- No database
- No API
- No external assets
- No build process
- No npm installation
- No server required

React via CDN may be used only if it works reliably as a standalone HTML file. Otherwise, the application should automatically use:

- HTML
- CSS
- Vanilla JavaScript

The preferred implementation is a fully self-contained HTML file.
