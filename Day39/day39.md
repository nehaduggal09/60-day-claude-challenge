# 📄 PDF Splitter & Merger

A premium single-page, browser-based PDF utility that allows users to split, extract, preview, reorder, and merge PDF files completely on the client side.

## ✨ Features

### 📑 PDF Splitter
- Upload PDF using file selection or drag-and-drop
- Automatically detect total page count
- Display visual page thumbnails
- Preview the PDF before splitting
- Split by specific page numbers
- Create custom page ranges
- Split after specific pages
- Split every N pages
- Extract selected pages
- Create multiple split ranges in one operation
- Validate page numbers and ranges
- Clearly highlight invalid inputs
- Preview resulting document structure
- Generate and download one or more PDF files

### 🔗 PDF Merger
- Upload multiple PDF files
- Drag-and-drop file upload
- Display uploaded files in a sortable list
- Show page count for every PDF
- Display visual previews
- Reorder PDFs using drag-and-drop
- Show total number of files
- Show total page count
- Preview the expected merged document
- Merge multiple PDFs into one PDF
- Download the final merged PDF

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Upload one or more PDF files.
4. Choose the Splitter or Merger tool.
5. Configure the required pages or file order.
6. Process the PDF.
7. Download the generated file.

No backend or database setup is required.

## 🔄 Application Workflow

### PDF Splitter
Upload PDF → Detect Pages → Generate Thumbnails → Preview Document → Select Split Method → Enter Page Ranges → Validate Input → Preview Output Structure → Process PDF → Download

### PDF Merger
Upload Multiple PDFs → Generate Previews → Display Page Counts → Reorder Files → Review Total Files & Pages → Preview Output → Merge PDFs → Download

## 🛡️ Error Handling

The application provides clear feedback for:

- Invalid PDF files
- Unsupported files
- Empty uploads
- Invalid page numbers
- Pages outside the document range
- Invalid page ranges
- Duplicate or conflicting selections
- Missing split selections
- PDF processing failures

Invalid inputs are clearly highlighted so users can quickly correct them.
