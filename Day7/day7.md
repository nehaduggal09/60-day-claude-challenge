## 🧠 Personalized Claude Usage Strategy

### 1. Daily Quotas & Token Allocation Strategy
- **Heavy Context Tasks (Morning - Peak Energy):** Reserve deep context prompts (e.g., full architecture reviews, multi-file code refactoring) for the start of the reset cycle.
- **Micro-Tasks (Afternoon/Evening):** Use short, targeted prompts for quick debugging, syntax validation, and drafting documentation.
- **Monitoring with Claude Counter:** Check usage meter before pasting large blocks of code or long prompt templates to avoid hitting limits unexpectedly.

### 2. Prompting Framework: The "Context-Constraint-Output" Model
1. **Context:** Provide concise background (language, frameworks, current state).
2. **Constraint:** Set strict rules (e.g., "Do not use external libraries", "Keep under 50 lines").
3. **Output:** Specify desired format (e.g., Markdown table, executable code block).

## 💡 Key Learnings & Strategic Takeaways

1. **Batching Queries Saves Context:** Sending all relevant code snippets in a single structured prompt avoids consuming multiple turn limits.
2. **Rate Limit Awareness:** Utilizing **Claude Counter** provides visual clarity on when to transition between deep reasoning tasks and quick syntax lookups.
3. **Modular Prompting:** Breaking large features into smaller functional units yields higher quality code.
