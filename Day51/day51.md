# SymptomCare 🩺

AI-powered healthcare assistant that suggests the right specialist based on your symptoms and shows real nearby clinics/hospitals — built as a 10-day capstone for the AB Talks 60-Day Claude AI Challenge.

## What it does
- Describe your symptoms in free text (Hindi or English)
- Claude AI suggests a likely specialist type + possible condition
- Emergency warning if symptoms indicate urgent care is needed
- Real nearby clinic/hospital search via Google Places API

## Status
🟢 **Day 1/10 — Complete**
Today: Problem discovery, PRD, and full 9-day implementation blueprint finalized.

## Tech Stack (planned)
HTML/CSS/JS · Vercel · Claude API · Google Places API

## Disclaimer
SymptomCare does not provide medical diagnosis. It offers general guidance only. Always consult a qualified doctor. In an emergency, contact local emergency services immediately.
