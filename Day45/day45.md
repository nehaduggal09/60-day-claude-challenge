# Decision Report — Green AI × Trustworthy AI Research Topic

An interactive HTML dashboard that walks through a structured decision-making process for picking a research paper topic, generated based on a real constraint: no working model, hard deadline, no room to redo the choice.

## Overview

This report evaluates three candidate topics at the intersection of **Green AI** and **Trustworthy AI**, and picks the most feasible one under time pressure.

**Candidate Options**
- **Option A** — Conceptual Framework Paper (no model required)
- **Option B** — Comparative Analysis of Green AI Techniques (uses published benchmarks)
- **Option C** — Case Study on a Real System (e.g. DistilBERT, MobileNet)

**Verdict:** Option A — Conceptual Framework Paper

## Features

- Decision matrix scoring each option across 7 dimensions with animated bar charts
- Assumption Buster highlighting cognitive biases (loss aversion, status quo bias)
- Premortem analysis for top-scoring options
- 7-day execution plan to complete the paper before the deadline
- Shareable summary cards for quick reference

## Tech Stack

- Pure HTML/CSS/JS — no build step, no dependencies
- Google Fonts (Inter)
- CSS keyframe animations for the decision matrix bars

## Usage

Open `decision_report.html` directly in any modern browser. Fully responsive down to mobile.
