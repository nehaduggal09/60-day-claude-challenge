How this was built

System prompt design

The assistant runs on one fixed system prompt with three internal "tasks": generate_question, give_feedback, and generate_plan. Each user-turn message tells Claude which task to run plus the structured context (job title, JD, resume, prior Q&A history). Claude is instructed to reply with strict JSON only matching a fixed schema per task, so the interface can parse and render it deterministically instead of guessing at free text. The prompt explicitly bans genuine job offers of advice like "you will get the job" and instead keeps feedback evidence-based (tied to STAR structure: Situation, Task, Action, Result). Edge cases are handled directly in the prompt: if the job description or resume look irrelevant, contradictory, or the user pastes something abusive/off-topic, Claude is told to return a JSON {"type":"clarify","message":"..."} block instead of forcing a question, and the UI surfaces that message as friendly guidance instead of crashing.

Why this UI

A generic chat box would bury the two things this niche actually needs: a clear sense of progress through a mock interview, and feedback that's scannable rather than a wall of text. So the interface uses a 3-step stepper (Setup → Mock Q&A → Prep Plan), a dedicated feedback layout (strength / improvement / rewritten example side-by-side) instead of prose, and a final "Prep Plan" report with categorized likely questions, gap chips, and next steps — closer to a coaching deliverable than a chat transcript.

Extending this

To go further: (1) add a tools call so Claude can pull real company interview questions from Glassdoor-style sources via web search before generating questions; (2) add memory by persisting the Q&A history and prep plan to local storage so a user can resume across sessions; (3) turn this into a true multi-step agent by letting Claude decide dynamically how many questions to ask based on how many weak spots it's found, rather than a fixed count; (4) add a lightweight scoring model that tracks STAR scores across the session and shows a trend line.

This tool gives interview practice and feedback for educational purposes. It does not guarantee interview outcomes. Your answers and documents are sent to Claude for analysis only.
