# ⚖️ Compare & Decide Builder

A premium research-driven decision-making tool that compares real-world options using verified data, measurable criteria, customizable weights, and transparent research methodology.

## 🚀 Features
- 📊 Compare multiple real-world options
- ⚖️ Customize criteria weights
- 🏆 Generate live weighted rankings
- 🔍 Use real, citable research sources
- 📚 Display every citation in a dedicated Sources Panel
- 🔬 Explain how each data point was researched
- ⚠️ Clearly flag estimates and synthetic placeholders
- 📈 Visualize comparison results
- 📱 Fully responsive design
- ⏳ Handle loading, empty, and edge states gracefully
- 🧠 Transparent and explainable comparison logic

## 🧮 Comparison Method
The application calculates results using weighted criteria:

**Overall Score = Σ (Normalized Criterion Value × Criterion Weight)**

Users can adjust the importance of each criterion and instantly see the ranking update.

## 🔎 Research Transparency
The collapsible **How this was researched** section explains:
- Source used for each data point
- Research methodology
- Conflicting information between sources
- Assumptions made during comparison
- Sourced facts vs estimates
- Synthetic placeholders, if any

## 🔗 Sources
A visible Sources Panel lists every citation used in the comparison so users can independently verify the underlying information.
