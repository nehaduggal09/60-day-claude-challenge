# Media Integrity Analyzer

An interactive, offline-first media literacy learning experience built as a single HTML file using pure HTML, CSS, and vanilla JavaScript.

## Overview

**Media Integrity Analyzer** is designed to teach users how to recognize misleading headlines, emotional manipulation, audience targeting, and other common media-literacy signals.

Instead of testing prior knowledge, the application uses a **guided discovery approach**:

1. Learn the concept in simple language.
2. Observe a fictional media scenario.
3. Make a decision.
4. Identify potential red flags.
5. Reveal the analysis.
6. Learn from the explanation.
7. Track media-literacy skills through live metrics.
8. Finish with a personalized Media Integrity Dashboard.

All scenarios are fictional and designed for educational purposes.

## Features

### 🎨 Theme Selection

Users can choose from multiple visual themes, including:

- Claude Orange
- Midnight Blue
- Emerald
- Violet

### 📰 Challenge 1 — Headline Detective

Users analyze a fictional news headline and matching article.

They are asked:

- Would you click this?
- Yes / Maybe / No
- Which parts appear exaggerated or misleading?

After submission, the application reveals:

- Headline Accuracy Score
- Highlighted mismatches
- Explanation
- Fair rewritten headline
- Key takeaway

### ❤️ Challenge 2 — Emotion Detector

Users analyze a fictional social-media post, reel caption, or article excerpt.

They identify:

- How the content makes them feel
- Which words influenced that feeling

The reveal includes:

- Target audience
- Intended emotional response
- Manipulation technique
- Highlighted emotional phrases
- Neutral rewrite
- Key takeaway

### 📊 Live Media Integrity Metrics

The application tracks:

- Headline Accuracy
- Source Reliability
- Emotional Manipulation
- Audience Targeting

Metrics update as users complete the challenges.

### 🧠 Media Integrity Dashboard

At the end, users receive:

- Overall Media Integrity Score
- What they learned
- Biggest red flag identified
- Three practical media-literacy habits
- Replay option with completely new scenarios

## Technical Details

The application is intentionally lightweight and portable.

### Technologies

- HTML5
- CSS3
- Vanilla JavaScript

### No Dependencies

The project does **not** require:

- Tailwind CSS
- npm
- Node.js
- Backend
- APIs
- Database
- External images
- External assets
- Build tools

Everything runs directly from a single HTML file.

## Running Locally

1. Download or clone the repository.
2. Open the HTML file in any modern web browser.
3. No installation or internet connection is required.
