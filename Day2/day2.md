# 🚀 Day 2: Lazy Prompt vs. Engineered Prompt

## 🎯 Objective
Compare the output quality, structure, and visual clarity between a basic ("lazy") prompt and a structured ("engineered") prompt using Claude.

---

## 🧪 Experiments & Prompts

### 1. The Lazy Prompt
> "Create an image explaining Prompt Engineering"

* **Result:** Generates a basic, high-level overview with minimal structure and generic suggestions.

### 2. The Engineered Prompt
> "Act as an expert AI educator and visual designer. Explain 'Prompt Engineering' in a clear, structured, and visually engaging manner..."

* **Result:** Delivers a comprehensive breakdown including role definition, component table, clear Before/After comparison, and precise infographic guidelines.

---

## 💡 Key Learnings & Takeaways
- **Context & Constraints Matter:** Giving the model a persona (Role) and precise structure drastically improves clarity and formatting.
- **Before/After Framing:** Explicitly requesting comparisons helps highlight the exact value of prompt optimization.
- **Actionable Visuals:** Detailed layout prompts result in far more useful infographic concepts than vague requests.
